# Credit Risk XGBoost MLOps

## Project 1: Home Credit Default Risk

A production-grade machine learning pipeline for predicting loan default probability.

### Tech Stack
- **Modeling:** XGBoost, Optuna (HPO)
- **Tracking:** MLflow
- **Data Validation:** Great Expectations
- **Serving:** FastAPI + Pydantic
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Infrastructure:** Terraform (S3 bucket)
